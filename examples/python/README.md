# Python Examples for CGL

This directory contains Python examples demonstrating various features of the CGL (Computer Graphics Library) using the Python wrapper.

## Examples

### Basic Examples
- **basic_window.py** - Simple window creation with basic OpenGL setup
- **basic_widgets.py** - Comprehensive widget demonstration with animations and interactivity

### Mathematical Visualizations
- **approximating_pi.py** - Monte Carlo method for approximating π with visualization
- **basic_plotting.py** - Data visualization with function plots, scatter plots, bar charts, and pie charts
- **mandelbrot_viewer.py** - Interactive Mandelbrot set fractal viewer with zoom functionality
- **triangle_fractal.py** - Sierpinski triangle fractal with chaos game and recursive rendering

### Games and Simulations
- **game_of_life.py** - Interactive Conway's Game of Life with pattern insertion and mouse drawing
- **simple_physics.py** - Physics simulation with bouncing balls, collisions, and particle effects

### Existing Examples
- **snake_game.py** - Classic Snake game implementation
- **tesseract.py** - 4D hypercube visualization with 3D projection
- **cube_waves.py** - 3D cube wave animation
- **chrome_dino.py** - Chrome dinosaur game clone
- **ascii_video.py** - ASCII art video renderer
- **3d_ai_hands.py** - 3D hand tracking visualization
- **curve_editor.py** - Bezier curve editor

## Running Examples

To run any example, you need to have the CGL Python wrapper installed. Navigate to the example directory and run:

```bash
python3 example_name.py
```

## Common Controls

Most examples support these common controls:
- **ESC** - Exit the application
- **Space** - Pause/Resume (where applicable)
- **Mouse** - Interactive features (clicking, drawing)
- **Number keys** - Mode switching (where applicable)

## Requirements

- Python 3.6+
- CGL Python wrapper (cgl-py)
- OpenGL support
- GLFW (for windowing)
